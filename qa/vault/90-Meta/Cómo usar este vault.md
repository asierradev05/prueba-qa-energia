# Cómo usar este vault

Este vault es Obsidian-ready: solo carpetas y `.md` con wikilinks, frontmatter opcional, tags y varios diagramas Mermaid.

## Abrirlo
1. Abre Obsidian → **Open folder as vault** → selecciona `qa/vault`.
2. Empieza en `index` → [[00-Inicio/Mapa de la prueba (MOC)]].

## Convenciones
- Cada nota empieza con **callouts** (`> [!danger]`, `> [!warning]`) para el veredicto.
- Fuente canónica siempre en `qa/*.md`; el vault es una **capa de navegación**.
- Tags: `#energia`, `#qa`, y uno de `#plan #humo #caja-negra #caja-blanca #defectos #seguridad #playwright #evidencias`.
- Los backlinks conectan defecto ↔ fase ↔ script de automatización.

## Plugins recomendados (opcionales)
- **Dataview** (consultas), **Mermaid** (ya incluido en Obsidian), **Canvas** (ver `Mapa.canvas`).
