```

{"pagination":{"page":-2,"size":10}} → 500
```

Código: `backend/internal/httpx/paging.go:48` `start := min((p.Page-1)*p.Size, len(items))` → negativo; `items[start:end]` hace panic. `Normalize()` no valida `page < 0` (`paging.go:23-35`). El middleware `Recover` responde 500.
